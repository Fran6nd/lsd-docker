# archetypes.txt -- the kinds of player a bot may be (bot/core/persona.h)
#
# A bot is drawn a KIND by the weights the server sets (the setting
# `archetypes`, lsd's `engine_bots_archetypes`: "camper:2,pusher:1"; every
# kind alike when unset), then each TRAIT around that kind's centre, with
# its spread (the standard deviation of a normal draw), kept within 0.2
# and 3. A centre of 1 is "no opinion"; 2, the trait counts about twice
# as much in a tree's `pick`. (bot/TREES.md, "What kind of player".)
#
# One line a kind:   <name> <trait>=<centre>/<spread> ... -- <its one line>
# A trait not named is drawn round 1 with a spread of 0.25.
#
# These are the built-in kinds, the numbers the engine has without this
# file (bot/core/persona.c; tests/kinds_test.c holds the two the same).
# AN OPERATOR'S OWN: a file of this name in the trees directory of the data
# volume (/data/trees/archetypes.txt) is read after this one -- a kind of a
# name here is replaced by his, a new name is a kind more, and may then be
# named in engine_bots_archetypes. A script may send a table too
# (botlink_set("archetype_table", text)): read over the built-in kinds.
